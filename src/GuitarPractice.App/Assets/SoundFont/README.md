# Instrument sounds for the MIDI player

`GeneralUser-GS.sf2` is **GeneralUser GS** by S. Christian Collins, a free General MIDI SoundFont
(https://schristiancollins.com/generaluser.php, source: https://github.com/mrbumpy409/GeneralUser-GS).

- Downloaded 2026-10-18 from the author's GitHub repository (`GeneralUser-GS.sf2`, 32,319,396 bytes,
  SHA-256 `9575028c7a1f589f5770fccc8cff2734566af40cd26ed836944e9a5152688cfe`).
- License (summary; see the author's site for the full text): free to use in software projects and for music
  creation, private or commercial; no attribution required. The author asks that public links point to the
  website rather than directly at the download files, and notes that a few samples came from other free banks
  whose origin can't be fully verified.

The app copies it next to the executable (`SoundFont/GeneralUser-GS.sf2`) at build time; the MIDI player
plays through it with MeltySynth (MIT).
